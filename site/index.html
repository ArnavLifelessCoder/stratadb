stratadb

An embedded key-value storage engine in C++20, built on the log-structured merge tree design behind LevelDB and RocksDB: a write-ahead log, a skiplist memtable, leveled SSTables with bloom filters, snapshots, and a block cache. Crash-tested with hundreds of kill cycles and benchmarked against LevelDB on the same machine.

How it is built

Write path

Writers queue; the leader appends the group as one WAL record with one sync, then inserts into an arena skiplist with lock-free readers.

Flush and manifest

A full memtable becomes an L0 table through write-temp, sync, rename; a manifest log of version edits names every live file and WAL.

Leveled compaction

The highest-scoring level is compacted, L0 by table count and deeper levels by size, with snapshot-aware version and tombstone dropping.

Reads

Memtables, then L0 newest first, then one table per level: key range, bloom filter, index, CRC-checked data block from a sharded LRU cache.

Iterators and snapshots

Streaming merging iterators pin their version; a table is deleted only after every version, iterator and snapshot using it is gone.

Testing

Differential tests against std::map over 10,000 seeds, fault injection, every-byte corruption checks, ASan and TSan in CI.
